Configuration Settings

Client Executable Config

Default settings for BNet.Cafe.Client.exe.config controlling server connection and auto-identification.

BNet.Cafe.Client.exe.config 
<?xml version="1.0" encoding="utf-8" ?>
<configuration>
	<startup>
		<supportedRuntime version="v4.0" sku=".NETFramework,Version=v4.8" />
	</startup>
	<appSettings>
		<!-- ==================================================================== -->
		<!-- SERVER CONNECTION SETTINGS                                           -->
		<!-- ==================================================================== -->
		<!-- WebSocket real-time communication endpoint -->
		<add key="WebSocketUrl" value="ws://192.168.1.2:2050" />

		<!-- BNet Cafe Server Web API base address -->
		<add key="AppUrl" value="http://192.168.1.2:2000/BNet.Cafe.Server/" />

		<!-- ==================================================================== -->
		<!-- CLIENT IDENTIFICATION SETTINGS                                       -->
		<!-- ==================================================================== -->
		<!-- 
		  CLIENT NAME CONFIGURATION:
		  
		  1. TRADITIONAL SETUP (Local Hard Drive):
		     - Set explicit PC name here (e.g., value="PC-01").
		     - Do NOT use spaces (e.g., use "PC-01" instead of "PC 01").
		     
		  2. DISKLESS SETUP (Shared Master Image):
		     - Leave value empty (value="").
		     - Client name will auto-resolve from local IP address offset:
		       * 192.168.1.101 -> PC-01
		       * 192.168.1.102 -> PC-02
		       * 192.168.1.103 -> PC-03
		-->
		<add key="ClientName" value="" />
	</appSettings>
</configuration>
WebSocket Server Endpoint

ws://192.168.1.2:2050

Defines the low-latency socket stream address used for real-time remote commands, live screen previews, and workstation lock states.

Web API Base Address

http://192.168.1.2:2000/BNet.Cafe.Server/

Base web directory for HTTP API requests, member authentication, account log transfers, and centralized server data.

Auto Client IP Offset
Diskless Ready

ClientName=""

When ClientName is empty, the software auto-calculates client IDs using the workstation's local IP address offset (e.g., 192.168.1.101 automatically resolves to PC-01).
